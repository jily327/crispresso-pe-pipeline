## Nonfinal run and evidence limits

An initial source run recorded 249 passes and two SOFTWARE_CHANGED failures while
the auditor committed and built packages in the same checkout. This was an
invalid qualification setup: source provenance includes Git HEAD/dirty state.
The safety guard was not altered. The entire focused source selection was rerun
serially from the fixed implementation commit after builds finished. The original
failure log remains included; only the clean terminal repeat is the final result.

The retained 1,999-test full baseline suite was not rerun: this change is confined
to GUI/export boundaries, with byte-preserved science and focused lifecycle,
recovery, browser, real Core and packaging checks. Previous full-suite results are
historical evidence, not counted as newly executed tests.

Actual Windows, WSL and Microsoft Excel were unavailable. Native Linux/Chromium,
mocked Explorer launch/exit behavior and real filesystem Excel lifecycle tests
were executed. No claim of observed Explorer desktop visibility is made.
Session-scoped generated-byte verification deliberately becomes explicitly
unauthenticated original-byte provenance after restart; matching scientific
Summary values are still checked. ALSW checks reuse rehashed qualified results,
not a new raw FASTQ scientific analysis.

`science-preservation.json` / `lifecycle-preservation.json` for preservation hashes.

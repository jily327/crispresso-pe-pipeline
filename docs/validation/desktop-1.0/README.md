## Limits and operational use

Actual Windows/WSL Explorer and BAT operation was **not manually tested** in this
Linux environment. Unit tests check argv construction, selection, timeouts,
nonfatal errors, trusted identities and one automatic attempt. Mocked launcher
checks cover stable-entry version updates, spaced paths, version-derived output
roots and Docker failure. No automated test launches a real desktop.

Excel generation is a GUI publication boundary; scientific CLI stages remain
unchanged. Discovery limits are four levels, 5,000 directories, 20,000 examined
entries and 500 candidates; unsupported results remain visible and are never
made compatible by weakening verification. Historical inputs and lineage paths
must remain available. Opening history is read-only; backup is not supported
workspace relocation. See `../../desktop-1.0.md` for setup and user behavior.

## Native reproducibility

Each completed, nonempty production cell records its native runs in `metrics/<sample>/<target>/native_runs.json`. It names the prepared population, exact staged input bytes, original targets, normalized references, actual command, resolved parameters, effective reference windows, native file identities and integer recount status. Open the listed native HTML and allele ZIP or use the GUI download controls. To replay outside PEAnalyzer, keep the script beside its two exact prepared mates and run `sh reproduce.sh /absolute/path/to/a/new/output`. Docker executes the pinned Core 2.3.4 directly. The standalone verifier compares all quantification integers, including event intersections, and row-order-independent allele identities/abundances. Native fractions and derived haplotypes retain their own denominators. A new production run has direct parity status NOT_RUN until an independent replay has been completed and documented. The separate qualification receipts bind each comparison to its original artifacts without mutating the signed workspace. [Standalone replay tool](direct_parity.py) · [Native counts by analysis and field](integrated/integer-parity.tsv) · [Input, command and artifact hashes](integrated/native-parity.json)
